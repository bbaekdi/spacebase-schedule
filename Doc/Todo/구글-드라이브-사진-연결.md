# Band 사진을 회사 구글 드라이브에 저장하기

- 상태: 할 일 · **회사 구글 계정 확인 뒤 시작** (2026-11-25 기준 사용자가 계정을 모름)
- 왜: 사진을 회사 구글 드라이브에 모아 두고 싶음. 그 전까지는 Cloudflare R2 임시 창고에 저장 (`우리-밴드.md`).
- 조건: 드라이브에 올릴 때도 **줄인 사진**(보통: 긴 쪽 1920픽셀, 약 300~500KB)으로.

| 단계 | 할 일 | 날짜(가안) |
|---|---|---|
| - [ ] 1 | 사용자가 회사 구글 계정(드라이브 주인) 확인 | 미정 |
| - [ ] 2 | 기획서 작성: 폴더 구조(예: 현장별/날짜별), 연결 방법, 용량(무료 15GB 인지 회사 요금제인지) | 미정 |
| - [ ] 3 | 새 사진부터 드라이브로 올라가게 바꾸기 | 미정 |
| - [ ] 4 | R2 에 있던 사진을 드라이브로 옮기기 | 미정 |
