# 자동 백업 체계

- 상태: 할 일 · 우선순위 2 · 예상: 1~2일
- 왜: 지금은 비밀번호를 아는 누구나(퇴사자 포함) 데이터를 지울 수 있고, 기록·복구가 없다.
- 지킬 것: 실제 데이터는 공개 저장소에 올리지 않는다. 테스트는 RTDB 에뮬레이터로.

| 단계 | 할 일 | 날짜(가안) |
|---|---|---|
| - [ ] 1 | 백업 방법 고르기 (예: 날짜별 스냅샷을 비공개 장소에 저장 / 변경 기록 남기기) — 사용자에게 객관식으로 묻기 | 2026-12-03 |
| - [ ] 2 | 백업 받을 장소 정하기 (공개 저장소 X, 새 서비스는 사용자 허락 필요) | 2026-12-03 |
| - [ ] 3 | 매일 자동 백업 만들기 + 에뮬레이터로 시험 | 2026-12-05 |
| - [ ] 4 | 되돌리기(복구) 방법 만들고 시험 | 2026-12-08 |
| - [ ] 5 | 사용자에게 복구 방법 짧게 안내 | 2026-12-09 |
