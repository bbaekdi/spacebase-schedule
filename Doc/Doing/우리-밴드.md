# 우리 밴드 (Band) — 네이버 밴드 대신 쓸 회사 게시판 — 기획서

- 상태: **하는 중** (2026-11-25 기획서 확인 완료, 준비물 단계) · 우선순위: **오늘부터 최우선** (2026-11-25 사용자 결정)
- 목표: **2027년 1월부터 직원 전체 사용**
- 예상 기간: 약 6~7주 (단계별로 나눠서 하나씩 올림)
- 영향: 웹사이트 전체 (새 메뉴 Band + **사이트 전체 로그인이 '초대받은 사람만'으로 바뀜**). 데스크톱 앱은 나중에 안 쓸 예정이라 지금 그대로 둠 → 앱 버전은 그대로.

## 1. 왜 하나 (목적)
- 지금은 네이버 밴드로 스케줄, 매일 현장 사진, A/S, 새 프로젝트 소식을 나눈다.
- 이것을 **우리 사이트 안의 "Band" 메뉴**로 옮겨, 스케줄·캘린더·게시판을 한곳에서 쓴다.
- 네이버 밴드는 바깥 프로그램에서 글을 쓰기 어려워 연결에 한계가 있었다 → 우리 것으로 만들면 자유롭게 연결할 수 있다.

## 2. 무엇을 만드나 (범위)
### 할 것
1. 상단 메뉴: **Home / Weekly Schedule / Calendar / Band**
2. 게시판 4개
   | 게시판 | 쓰임 |
   |---|---|
   | 현장 사진 | 매일 공사 현장 사진 (하루 약 30장 이하) |
   | A/S | 예전 현장에서 들어온 A/S. **처리 상태 관리** (접수 → 처리 중 → 완료, 담당자) |
   | 프로젝트 | 새 프로젝트 소개. 등록하면 그 **현장 방**이 생김 |
   | 공지·자유글 | 회사 공지와 그 밖의 이야기 |
3. **현장별로 묶기**: 현장 사진·A/S 를 올릴 때 현장을 고른다 → 한 현장의 사진·A/S 를 날짜순으로 모아 본다.
4. 글 기능: **댓글, 읽음 확인, 새 글 알림(휴대폰), 검색**(현장 이름·글 내용)
5. 사진: 휴대폰에서 찍어 바로 올리기, 여러 장 한 번에. **올리기 전에 휴대폰 안에서 줄인다**
   - "보통": 긴 쪽 1920픽셀, 한 장 약 300~500KB (원본 3~5MB 의 약 1/10)
6. 로그인: **구글 계정 + 관리자가 받아 준 사람만** (사이트 전체: Home / Weekly Schedule / Calendar / Band)
   - 구글 계정만 있다고 들어올 수 없다. 아래 "회원 관리"를 거친 사람만 들어온다.
7. 지우기: **쓴 사람 + 관리자**만. 지운 글은 30일 동안 휴지통에 남겨 되돌릴 수 있게. 누가 지웠는지 기록.
8. 관리자: 구글 로그인 후 **관리자 비밀번호**를 넣으면 관리자가 됨. 관리자는 다른 직원을 관리자로 올릴 수도 있음. (모든 글 지우기, 현장 관리, 휴지통 복구, 회원 관리)
9. **회원 관리 (초대받은 사람만)** — 2026-11-25 사용자 결정
    | 방법 | 어떻게 |
    |---|---|
    | 초대 링크 | 관리자가 "초대 링크 만들기" → 카톡 등으로 보냄 → 받은 사람이 링크를 열고 구글 로그인하면 바로 가입. **1명용, 7일 동안만** 쓸 수 있음 (한 번 쓰면 끝, 남에게 퍼져도 안전) |
    | 가입 신청 | 링크 없이 구글 로그인한 사람은 "승인 대기" 화면만 보임 → 관리자가 회원 관리 화면에서 이름·메일을 보고 "승인" 또는 "거절" |
    | 이름 연결 | 승인(또는 링크 가입)할 때 관리자가 **주간 스케줄 직원표의 이름**을 골라 연결 → 이름표, 홈 프로필(직급·팀), 글쓴이 이름이 정확히 맞음 |
    | 퇴사 | 관리자가 "내보내기" → 그 즉시 못 들어옴. 그 사람이 쓴 글·사진은 그대로 남음 |
    - 회원 관리 화면: 회원 목록(이름, 메일, 관리자 여부, 가입일), 승인 대기 목록, 초대 링크 목록(사용 여부·남은 기간), 내보내기 버튼.
10. 휴대폰·PC 둘 다 (직원 10~30명, 주로 휴대폰, 휴대폰은 갤럭시·아이폰 반반)

### 안 할 것 (지금은)
- 네이버 밴드 예전 글 전부 옮기기 → **진행 중인 현장과 안 끝난 A/S 만 사람이 새로 등록**
- 구글 드라이브 저장 → 회사 구글 계정 확인 뒤 `구글-드라이브-사진-연결.md` 에서
- 채팅(대화방), 동영상 올리기

## 3. 화면·사용 방법 (그림 대신 글로)
- **Band 첫 화면**: 위에 게시판 탭(전체 / 현장 사진 / A/S / 프로젝트 / 공지·자유글), 검색창, 오른쪽 아래 "＋ 글쓰기" 버튼. 글은 최신순 카드로.
- **글쓰기**: 게시판 고르기 → (현장 사진·A/S 면) 현장 고르기 → 글 → "사진 추가"(휴대폰 사진첩/카메라) → 올리기. 사진은 줄어드는 동안 진행 표시.
- **현장 방**: 프로젝트(현장)를 누르면 그 현장의 소개, 사진(날짜별), A/S 목록.
- **A/S**: 카드에 상태 표시(접수=빨강, 처리 중=노랑, 완료=회색). "안 끝난 A/S 만 보기" 버튼.
- **글 상세**: 사진 크게 보기(밀어서 넘기기), 댓글, "읽은 사람 N명"(누르면 이름).
- **알림**: 새 글이 올라오면 휴대폰 알림. 아이폰은 사이트를 "홈 화면에 추가"해야 알림이 옴 → 안내 화면 제공.
- 홈(Home)에 "Band 새 글" 카드 추가.

## 4. 어떻게 만드나 (바꿀 파일·쓸 것)
| 할 일 | 방법 |
|---|---|
| 화면 | 새 파일 `public/band.html`, `public/band.js`, 공통 `ws.css`/`ws-common.js` 에 메뉴 추가 |
| 글·댓글·읽음 저장 | Firebase (지금 쓰는 곳). 새 위치 `board/...` (기존 스케줄 데이터와 따로) |
| 구글 로그인 | Firebase 의 구글 로그인 기능 (사용자가 Firebase 화면에서 켜기 1번 필요) |
| 사진 창고 | **Cloudflare R2 무료 창고** (10GB 무료, 하루 30장이면 약 2년치). 사진은 지금 쓰는 Cloudflare 중계(`worker/`)를 거쳐 저장 |
| 사진 줄이기 | 휴대폰/PC 브라우저 안에서 줄인 뒤 올림 (서버 비용 없음) |
| 휴대폰 알림 | 사이트를 앱처럼 설치되게(홈 화면 추가) + Cloudflare 중계가 알림 보냄 |
| 관리자 | 관리자 비밀번호는 GitHub Secret `ADMIN_CODE` 에만. GitHub Actions 가 비밀번호를 알아볼 수 있는 "열쇠 모양"(해시)만 Firebase 의 아무도 못 읽는 칸에 넣고, Firebase 규칙이 맞는지 확인 |
| 회원·초대 확인 | Firebase 규칙(누가 무엇을 읽고 쓸 수 있는지 정한 규칙)으로: 회원 명단에 있는 구글 계정만 데이터 읽기, 초대 링크는 안 쓴 것·7일 안 지난 것만 가입 가능 |
| 규칙 올리기 | 지금은 Firebase 화면에서 손으로 바꾸던 규칙을, 새 GitHub Actions(`firebase-rules.yml`)가 `FIREBASE_SERVICE_ACCOUNT` 로 자동으로 올림 (규칙 파일은 저장소에 두고 검토 후 반영) |
| 기존 데이터 | 주간 스케줄·캘린더는 지금 자리(`spaces/<해시>`) 그대로. 웹은 로그인한 회원에게만 그 자리 이름을 알려 줌 → 회사 비밀번호를 몰라도 들어감. 데스크톱 앱용 길은 전환 뒤에 잠금 |

## 5. 조심할 점
- **보안**: 저장소는 공개 → 직원 이름, 현장 이름, 사진, 관리자 비밀번호는 코드·문서에 절대 안 씀. 사진 주소는 로그인한 직원만 볼 수 있게.
- **데이터**: 기존 주간 스케줄·캘린더 데이터는 건드리지 않는다. 새 위치에만 저장. 시험은 에뮬레이터(가짜 연습용 Firebase)로.
- **로그인 변화**: 웹사이트는 전체가 "구글 로그인 + 초대받은 사람만"으로 바뀜. 지금 쓰는 직원 모두가 바뀌는 날 전에 초대·승인을 받아야 함 → 첫 초대는 시험 사용 전에 한꺼번에.
- **데스크톱 앱(뒷문)**: 데스크톱 앱은 지금처럼 회사 비밀번호로 둔다. 그래서 그동안은 회사 비밀번호를 아는 사람이 주간 스케줄·캘린더 데이터에 들어갈 수 있다 (새 문을 달았지만 뒷문이 남은 셈). **직원들이 웹사이트로 다 옮겨 오면 뒷문(회사 비밀번호 길)을 잠근다** (`직원-웹사이트-전환.md`). Band 데이터는 처음부터 초대받은 사람만.
- **데이터 옮기기**: 주간 스케줄·캘린더 데이터는 지금 자리 그대로 쓴다 (옮기지 않음). 들어오는 문만 바꾼다.
- **비용**: R2 는 처음 켤 때 결제카드 등록을 요구할 수 있음 (10GB 안에서는 0원). 넘을 것 같으면 미리 알림.
- **캘린더**: 지금 캘린더의 "밴드 일정"은 네이버 밴드에서 읽어 옴 → 네이버 밴드를 그만 쓰면 일정도 우리 캘린더에 직접 넣어야 함. (`밴드캘린더-기능-웹으로.md` 와 함께 정리)
- **휴대폰**: 갤럭시·아이폰 둘 다에서 사진 올리기·알림을 꼭 시험.
