# Band 사진 올리기 — 회사 구글 드라이브에 저장 — 기획서

> 사용자 확인을 받은 뒤에 개발을 시작한다. (2026-11-27 사용자 결정: 카드가 없으니 R2 대신 회사 구글 드라이브, 범위는 기획서대로 전부)

- 상태: 하는 중 (사용자 확인 대기) · 우선순위 1 · 영향: 웹만 (Band) → 버전 그대로, 릴리즈 노트 `## 웹`

## 1. 왜 하나
- Band 에 현장 사진을 올리고 싶다. 사진 보관 창고(R2)는 결제카드가 필요해서, 카드 없이 쓸 수 있는 회사 구글 드라이브에 저장한다.

## 2. 무엇을 만드나 (범위: 기획서대로 전부)
1. 글쓰기에서 "사진 추가": 휴대폰 사진첩·카메라, 여러 장 한 번에.
2. 올리기 전에 휴대폰 안에서 줄이기 (긴 쪽 1920픽셀, 약 300~500KB). 줄이는 동안·올리는 동안 진행 표시.
3. 줄인 사진을 Cloudflare 중계(`worker/`)가 구글 드라이브 폴더에 저장 (로그인한 회원만).
4. 글 카드·현장 방(날짜별)에서 사진 보기, 크게 보기(밀어서 넘기기).
5. 글을 지우면 사진도 같이 휴지통 정리.
- 안 할 것: 이미 올라간 밴드(네이버) 사진 옮기기.

## 3. 방법 (쉬운 말)
- 사진은 직원 브라우저 → Cloudflare 중계 → 회사 드라이브 폴더. 중계는 "회사 드라이브 담당 열쇠"(새로 한 번 받는 구글 허락)로 드라이브에 올려요. 직원 개인 드라이브에는 아무것도 안 닿아요.
- 사진을 볼 때도 중계를 거쳐서 로그인한 회원에게만 보여 줘요. 사진 주소를 알아도 로그인 안 하면 못 봐요.
- 열쇠(구글 허락 토큰)는 GitHub Secret 에만 두고 코드·채팅에는 안 써요. 허락 화면은 사용자가 직접 눌러요.
- 폴더: `Band 사진/현장이름/날짜/` 형태(현장 이름은 드라이브 폴더 이름에만 쓰이고 저장소에는 안 올라가요).
- Firebase 에는 글에 "사진 번호 목록"(드라이브 파일 번호, 크기)만 저장.

## 4. 사용자 준비물 (제가 화면 순서대로 안내)
1. 어느 구글 계정의 드라이브에 둘지 정하기 (회사 구글 워크스페이스 계정 권장).
2. 구글 클라우드 화면에서 "Google Drive API" 켜기 (이미 개인 캘린더 연결에 쓰는 같은 프로젝트).
3. 같은 구글 클라우드 화면에서 OAuth 클라이언트에 승인된 리디렉션 URI `https://<중계 주소>/drive/callback` 한 줄 추가.
4. 사이트의 회원 관리 → "사진 보관" 카드 → "회사 드라이브 연결하기" → 회사 구글 계정으로 "허용" (열쇠는 Secret 이 아니라 Firebase 비공개 칸에 자동 저장되어 복사할 것이 없음. "Band 사진" 폴더도 자동으로 만들어짐).

## 5. 바꿀 파일 (예정)
- `worker/drive.js`(새), `worker/band-relay.js`(길 연결), `.github/workflows/band-worker.yml`(Secret 전달)
- `public/band.js`, `public/band.css`, `public/band.html`(사진 추가·보기·크게 보기), `firebase/database.rules.json` + `rules.test.mjs`(글의 사진 목록 칸)
- `tools/test/e2e-band.cjs`, `tools/test/drive.test.mjs`(새, 가짜 드라이브로 중계 시험), `README.md`, `RELEASE-NOTES.md`

## 6. 조심할 점
- 보안: 공개 저장소 → 사진·현장 이름·열쇠를 코드/문서에 안 넣음. 시험은 가짜 드라이브(내 컴퓨터)와 연습용 Firebase 에서만.
- 데이터: 기존 글은 그대로 (사진 칸이 없는 글도 잘 보여야 함).
- 용량: 개인 무료 계정은 15GB(메일·사진과 공유), 회사 요금제는 더 큼. 하루 30장 × 400KB ≈ 12MB → 15GB 도 3년 이상.
- 휴대폰: 갤럭시·아이폰 둘 다에서 사진 올리기 시험. 아이폰 사진(HEIC)은 브라우저가 줄이면서 JPEG 로 바꿈.
- 구글 허락 열쇠가 끊기면(비밀번호 바꿈 등) 사진 올리기가 멈춤 → 화면에 "사진 연결이 끊겼어요, 관리자에게 알려 주세요" 안내.

## 7. 확인 방법
- [ ] 사진 여러 장을 골라 올리면 줄어서(약 500KB) 드라이브 폴더에 저장
- [ ] 글 카드·현장 방에서 사진이 보이고, 크게 보기가 됨
- [ ] 로그인 안 한 사람은 사진을 못 봄
- [ ] 글을 지우면 사진도 정리
- [ ] 가짜 드라이브 시험·Band 화면 시험·`tools/check.sh` 통과, 갤럭시·아이폰 확인
