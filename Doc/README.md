# Doc — 할 일 관리

할 일 하나 = 파일 하나. 파일 안에 **단계별 체크리스트 + 날짜**(계획 일정표)를 적는다.

| 폴더 | 뜻 |
|---|---|
| `Todo/` | 앞으로 할 일 |
| `Doing/` | 지금 하는 일 |
| `Done/` | 끝난 일 (기록용) |

## 쓰는 법
- **개발 전에 기획서부터**: `기획서-양식.md` 를 복사해 `Todo/` 에 기획서를 쓰고, 사용자 확인 후 개발을 시작한다. (아래 Todo 파일들은 아직 간단한 일정표뿐이라, 시작할 때 양식에 맞춰 기획서로 채운다.)
- 일을 시작하면 파일을 `Todo` → `Doing` 으로 옮기고, 끝나면 `Done` 으로 옮긴다. (Claude 에게 "백업 작업 시작하자" 라고만 말하면 Claude 가 옮긴다.)
- 체크: `- [ ]` 할 것, `- [x]` 끝남.
- 날짜에 "가안"이라고 적힌 것은 임시 날짜. 시작할 때 다시 정한다.
- 파일 이름: `할일이름.md` (끝난 일은 `YYYY-MM-DD-할일이름.md`).
- **이 저장소는 공개다.** 직원 이름, 프로젝트명, 비밀번호, 밴드 주소 같은 회사 정보는 적지 않는다.
