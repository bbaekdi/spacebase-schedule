# Site 공정표 — 바로 고치기 (+ − 버튼) · 되돌리기 보완 — 기획서

> 사용자 확인을 받은 뒤에 개발을 시작한다.

- 상태: 끝남 · 우선순위 1 · 예상 1일 · 영향: 웹만 (Site)

## 1. 왜 하나
- "공정 목록 고치기"로 들어가야만 줄을 고칠 수 있어 번거롭다. 표에서 바로 줄을 넣고 빼고 이름을 고치고 싶다.
- Ctrl+Z 로 되돌릴 때 칸만 지워지고 공종 상세(줄)가 안 지워지는 경우가 있다고 한다 (아래 질문으로 상황 확인).

## 2. 무엇을 만드나
1. 표의 모든 줄에 바로 쓰는 [＋](아래에 줄 추가) · [－](줄 삭제) 버튼.
2. 공종 상세(공정 이름) 칸을 눌러 바로 글자 수정 (Enter/다른 곳 누르면 저장).
3. "공정 목록 고치기" 버튼·모드는 없앰 (같은 기능 반복 금지).
4. Ctrl+Z 되돌리기 보완 (정할 것 참고).

## 3. 사용자가 정한 것
- 줄 추가(+) 뒤 Ctrl+Z → 줄까지 한 번에 사라지게
- ＋ － 는 마우스 올릴 때만, 휴대폰은 안 나옴
- ↑↓ 대신 엑셀처럼 줄을 선택해 위아래로 (⋮⋮ 끌기 · Alt+↑/↓)
- 공종 칸도 바로 수정

## 4. 바꿀 파일: `public/site.js`, `public/site.css`, `tools/test/e2e-site.cjs`, `README.md`, `RELEASE-NOTES.md`
## 5. 조심할 점: 줄 삭제는 확인 없이 지우되 Ctrl+Z 로 복구 가능해야 함(공종 상세 포함). 예전 데이터·옛 공정(공종 없음)은 그대로.
## 6. 확인 방법: 모드 없이 +/− 로 줄 추가·삭제 · 이름 바로 수정 · Ctrl+Z 로 줄까지 복구 · 시험 통과
## 7. 일정표: 기획서 확인 → 개발 → 시험·검토 → 배포 (11-27~28)
