개인정보 처리방침

SPACEBASE 사내 워크스페이스 (주간 스케줄 · 회사 캘린더) · 시행일 2026년 11월 24일

이 서비스는 주식회사 스페이스베이스 구성원이 회사 일정과 개인 일정을 한곳에서 보기 위한 사내용 웹사이트입니다.

1. 구글 캘린더 연결 시 이용하는 정보

  • 구글 계정의 이름과 이메일 주소: 연결된 계정을 화면에 표시하기 위해 사용합니다.
  • 구글 캘린더 목록과 일정(읽기 전용): 이용자 본인의 화면에 일정을 표시하기 위해서만 사용합니다.

2. 보관 방법

  • 구글 연결 정보는 암호화되어 이용자 본인의 브라우저에만 저장됩니다. 회사 서버나 데이터베이스에는 저장하지 않습니다.
  • 구글 캘린더 일정은 이용자의 브라우저가 구글에서 직접 불러와 화면에 표시하며, 별도로 저장하거나 다른 사람에게 보여 주지 않습니다.
  • 로그인 중계 서버(Cloudflare Workers)는 구글 로그인 처리만 하며 어떤 정보도 기록·보관하지 않습니다.

3. 제3자 제공

구글 사용자 데이터를 제3자에게 제공·판매하거나 광고에 사용하지 않습니다. 구글 API 서비스에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 연결 해제

캘린더 화면의 "내 구글 캘린더 → 연동해제"를 누르면 브라우저에 저장된 연결 정보가 삭제되고 구글에 대한 접근 권한도 해제됩니다. 구글 계정 설정(myaccount.google.com/permissions)에서도 언제든 해제할 수 있습니다.
