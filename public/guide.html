SPACEBASE 워크스페이스 사용 안내

주간 스케줄, 회사 캘린더(밴드 일정), 내 구글 캘린더와 할 일을 한 곳에서 보는 사내 웹사이트예요. PC, 태블릿, 휴대폰 어디서든 인터넷 주소로 열면 돼요.

1처음 로그인하기

모두 해 주세요. 기기마다 처음 한 번만 하면 돼요.

  1. 위의 노란 주소 버튼을 눌러 웹사이트를 열어요. 자주 쓰니 즐겨찾기(PC는 Ctrl + D)나 휴대폰 홈 화면에 추가를 해 두면 편해요.
  2. 로그인 창이 뜨면 회사 비밀번호와 내 이름(예: 홍길동)을 넣고 시작해요.
    회사 비밀번호는 주간 스케줄 프로그램에서 쓰던 것과 같아요. 모르면 담당자에게 물어보세요. 비밀번호는 단체방이나 메일에 그대로 올리지 말아 주세요.
  3. 이름은 주간 스케줄 구성원 표에 적힌 이름과 똑같이 써 주세요. 그래야 홈 화면에 직급과 팀이 함께 나와요.
  4. 홈 화면이 열리면 끝이에요. 위쪽 메뉴에서 Home Weekly Schedule Calendar로 옮겨 다녀요. (휴대폰은 화면 아래쪽 메뉴)
알아두기 한 번 로그인하면 그 기기에서는 다음부터 바로 열려요. 공용 PC라면 오른쪽 위 로그아웃을 눌러 주세요.

2밴드 자동 입력 설치 (확장 프로그램)

PC의 크롬, 엣지, 웨일에서 일정을 추가할 사람만 해 주세요. PC마다 한 번, 1분이면 돼요.

밴드는 바깥에서 일정을 바로 써 넣는 기능을 열어 주지 않아요. 그래서 이 확장 프로그램이 대신, 우리 사이트에서 쓴 일정을 밴드의 일정 만들기 창에 자동으로 채워 줘요. 완료는 내가 직접 눌러요.

  1. 웹사이트를 PC에서 열면 화면 아래에 설치하기 안내가 떠요. 누르면 설치 안내 화면으로 가요. (안내가 안 보이면 설치 안내 화면을 바로 열어도 돼요.)
  2. 설치 파일 받기 (zip)를 눌러 파일을 받고, 마우스 오른쪽 → 압축 풀기로 풀어요.
    중요 풀린 폴더는 지우지 말고 문서 폴더 같은 곳에 그대로 두세요. 폴더를 지우면 확장 프로그램도 꺼져요.
  3. 주소창에 아래 주소를 넣고 엔터를 눌러요.
    크롬 chrome://extensions · 엣지 edge://extensions · 웨일 whale://extensions
  4. 오른쪽 위(엣지는 왼쪽 아래)의 개발자 모드를 켜요.
  5. 압축해제된 확장 프로그램을 로드합니다(엣지는 "압축 풀린 항목 로드")를 누르고, 2번에서 푼 폴더를 골라요.
  6. 목록에 SPACEBASE 밴드 일정 자동 입력이 보이면 끝이에요. 사이트로 돌아가 Ctrl + F5로 새로고침해요.
이렇게 써요 홈의 + 일정 추가 또는 캘린더의 + 밴드에 일정 추가에서 일정을 쓰고 밴드에 입력하기를 누르면, 밴드가 열리면서 칸이 채워져요. 확인하고 완료만 누르면 모두의 캘린더에 들어가요. 밴드에는 미리 로그인해 두세요.
  • 휴대폰에서는 확장 프로그램을 쓸 수 없어요. 휴대폰에서는 밴드 앱에서 직접 일정을 추가해 주세요.
  • 화면 아래 설치 안내를 지금 하고 싶지 않으면 나중에를 누르세요. 7일 뒤에 다시 알려 줘요.

3내 구글 캘린더 · 할 일 연결

원하는 사람만 해 주세요. 연결한 내용은 나에게만 보이고, 다른 팀원 화면에는 나오지 않아요.

  1. 위쪽 메뉴에서 Calendar로 가서 내 구글 캘린더 버튼을 눌러요.
  2. G  구글 계정으로 연결을 누르고, 내 구글 계정을 골라요.
  3. 구글이 권한을 물어보면 캘린더 보기와 할 일(Tasks)에 체크하고 계속을 눌러요.
    참고 "Google에서 확인하지 않은 앱"이라는 화면이 나오면 회사에서 직접 만든 사이트라서 그래요. 고급 → SPACEBASE(으)로 이동을 누르면 계속할 수 있어요.
  4. 사이트로 돌아오면 내 캘린더 목록이 나와요. 보고 싶은 캘린더만 체크하면 바로 반영돼요.
  5. 이제 캘린더에 내 구글 일정이 초록색으로 함께 보이고, 홈과 캘린더 화면의 TO DO LIST에 구글 할 일이 나와요. + 할 일 추가 칸에 쓰고 엔터를 누르면 구글 할 일에도 바로 들어가요.
알아두기
  • 구글에서 바꾼 일정이 늦게 보이면 내 구글 캘린더 → 지금 동기화를 눌러요.
  • 잠깐 숨기고 싶으면 캘린더 화면의 구글 캘린더 보기를 끄면 돼요. 연결을 끊으려면 연동해제를 눌러요.
  • 연결 정보는 그 기기의 브라우저에만 저장돼요. 다른 PC나 휴대폰에서도 보려면 그 기기에서 한 번 더 연결해 주세요.
궁금한 점이나 고쳤으면 하는 부분은 담당자에게 알려 주세요.
