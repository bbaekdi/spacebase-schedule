밴드 자동 입력 설치

설치하면 캘린더의 ＋ 밴드에 일정 추가에서 일정을 쓰고 "밴드에 입력하기"를 누를 때, 밴드가 열리면서 일정 만들기 창이 자동으로 채워져요. PC의 크롬·엣지·웨일에서만 되고, 휴대폰에서는 지금처럼 밴드에서 직접 추가해요. PC마다 한 번씩 설치해야 해요.

설치 파일 받기 (zip)

설치 방법 (1분)

  1. 위 설치 파일 받기를 눌러 받은 zip 파일을 마우스 오른쪽 → 압축 풀기로 풀어요. 풀린 폴더는 지우지 말고 그대로 두세요. (예: 문서 폴더)
  2. 주소창에 아래 주소를 넣고 엔터를 눌러요.
    크롬: chrome://extensions · 엣지: edge://extensions · 웨일: whale://extensions
  3. 오른쪽 위(엣지는 왼쪽 아래) 개발자 모드를 켜요.
  4. 압축해제된 확장 프로그램을 로드합니다(엣지: "압축 풀린 항목 로드")를 누르고, 1번에서 푼 폴더를 골라요.
  5. "SPACEBASE 밴드 일정 자동 입력"이 목록에 보이면 끝! 캘린더 화면을 새로고침(Ctrl+F5)하세요.

밴드에는 미리 로그인해 두세요. 자동 입력은 내용을 채우기만 하고 완료는 직접 눌러요. 혹시 채워지지 않은 칸이 있으면 밴드 화면 오른쪽 위에 알려 줘요.
